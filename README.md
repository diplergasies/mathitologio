# Μαθητολόγιο ΣΕΠ — Οδηγός Χρήσης

Ψηφιακό μαθητολόγιο για δομή φιλοξενίας αιτούντων άσυλο. Εφαρμογή υπολογιστή (Windows) που τρέχει
**τοπικά και offline** — τα δεδομένα των μαθητών δεν φεύγουν ποτέ από τον υπολογιστή.

---

## Γρήγορη ροή εργασίας

1. **Ρυθμίσεις** → καταχώρισε στοιχεία ΣΕΠ, το έτος Προνηπίου και τα σχολεία ευθύνης σου.
2. **Εισαγωγή XLSX** → φόρτωσε το αρχείο πληθυσμού· κρατούνται αυτόματα μόνο οι μαθητικής ηλικίας.
3. **Αφίξεις** → εγγραφή των μαθητών που μένουν / διαγραφή όσων φεύγουν.
4. **Μαθητές** → ανάθεση σχολείου & τάξης, έκδοση εγγράφων.
5. **Διαγραφές** → επαναφορά λανθασμένων διαγραφών ή οριστική διαγραφή.

---

## Καρτέλες

> Σε **Αφίξεις**, **Μαθητές** και **Διαγραφές** υπάρχει πεδίο **«Εύρεση μαθητή…»**: καθώς πληκτρολογείς,
> η λίστα φιλτράρεται ζωντανά σε **όλα τα στοιχεία** του μαθητή (όνομα, ΔΙΚΑ, ιθαγένεια, σχολείο, κ.ά.,
> αγνοώντας τόνους/πεζά-κεφαλαία) και το τμήμα που ταιριάζει **χρωματίζεται**. Σε όλες τις λίστες
> εμφανίζονται οι στήλες **Μονάδα** και **ΔΙΚΑ** κάθε μαθητή.

> Σε **Αφίξεις** και **Μαθητές** εμφανίζεται δίπλα στο πλήθος μια ένδειξη **«Τελευταία λίστα: …»** με το
> όνομα του αρχείου που εισήχθη πιο πρόσφατα και την ημερομηνία του — για να ξέρεις πάντα ποια λίστα
> χρησιμοποιήθηκε τελευταία.

### Αφίξεις
Μαθητές που μόλις εισήχθησαν και δεν έχουν εγγραφεί ακόμη.
- **Εγγραφή** → μεταφέρει τον μαθητή στους «Μαθητές». Αν υπάρχει **ακριβώς ένα** κατάλληλο σχολείο για
  την ηλικία του, ανατίθεται αυτόματα· αλλιώς η εγγραφή γίνεται με **κενό σχολείο** (επιλέγεται μετά).
- **Διαγραφή** → μεταφέρει στις «Διαγραφές».
- **Ταξινόμηση**: κλικ στην κεφαλίδα **Ημ. γέννησης** (ηλικιακή) ή **Προτεινόμενη τάξη** (ανά βαθμίδα).
  Διαδοχικά κλικ: αύξουσα → φθίνουσα → προεπιλεγμένη σειρά.
- **Μαζική διαγραφή με ΔΙΚΑ** (κουμπί πάνω δεξιά): επικολλάς αριθμούς ΔΙΚΑ χωρισμένους με κόμμα,
  βλέπεις ποιοι μαθητές ταιριάζουν (και ποιοι ΔΙΚΑ δεν βρέθηκαν) και τους διαγράφεις μαζικά.

### Μαθητές
Οι εγγεγραμμένοι μαθητές.
- **Σχολείο**: κλικ στο κελί → εμφανίζονται τα σχολεία που ταιριάζουν στην ηλικία του μαθητή → επιλογή.
  Κενό (κίτρινο) κελί σημαίνει ότι εκκρεμεί επιλογή σχολείου.
- **Τάξη**: ανατίθεται αυτόματα βάσει ηλικίας, αλλά αλλάζει με **κλικ** (π.χ. τοποθέτηση στην Α′ λόγω
  γλώσσας, ανεξαρτήτως ηλικίας).
- **Επίτροπος**: εναλλαγή Ναι/Όχι με κλικ.
- **Έκδοση εγγράφων** (📄) → δημιουργία PDF με συμπληρωμένα στοιχεία (αποθήκευση & άνοιγμα φακέλου).
- **Διαγραφή** (🗑️) → μεταφορά στις «Διαγραφές».
- **Ταξινόμηση**: κλικ στην κεφαλίδα **Σχολείο** (αλφαβητικά) ή **Ημ. γέννησης** (ηλικιακή).
- **Μαζική διαγραφή με ΔΙΚΑ** (κουμπί πάνω δεξιά): όπως στις Αφίξεις — επικόλληση ΔΙΚΑ με κόμμα,
  preview και μαζική διαγραφή.

### Διαγραφές
Διαγραμμένοι μαθητές, με **ημερομηνία διαγραφής**.
- **Επαναφορά** → επιστροφή στην προηγούμενη κατάσταση (Μαθητές ή Αφίξεις).
- **Οριστική διαγραφή** (🗑️) → **μη αναστρέψιμη** αφαίρεση από τη βάση.

### Ρυθμίσεις
- **Στοιχεία ΣΕΠ**: Ονοματεπώνυμο, Νομός, Δομή — συμπληρώνονται αυτόματα στα έγγραφα.
- **Έτη γέννησης ανά τύπο σχολείου**: συμπληρώνεις το έτος του **Προνηπίου** και υπολογίζονται αυτόματα
  όλες οι βαθμίδες (Νηπιαγωγείο 2, Δημοτικό 6, Γυμνάσιο 3, Λύκειο/ΕΠΑΛ 3 έτη). Αυτό καθορίζει τη διαλογή
  ηλικιών και την κατάταξη σε τάξη.
- **Σχολεία ευθύνης**: προσθήκη/επεξεργασία/διαγραφή σχολείων (όνομα + τύπος).
- **Προβιβασμός / Νέο σχολικό έτος**: ανοίγει πίνακα με όλους τους εγγεγραμμένους και την **επόμενη
  τάξη** τους (προεπιλογή: όλοι προβιβάζονται). Ξετσεκάρεις όσους μένουν στην ίδια τάξη. Με την εφαρμογή:
  οι προβιβασμένοι πάνε στην επόμενη τάξη (στα όρια βαθμίδας αλλάζουν τύπο σχολείου — π.χ. ΣΤ′ Δημοτικού →
  Α′ Γυμνασίου, με αυτόματη ή κενή ανάθεση σχολείου), οι **απόφοιτοι** (Γ′ Λυκείου/ΕΠΑΛ) μεταφέρονται στις
  **Διαγραφές**, και το **σχολικό έτος προχωρά κατά 1**.

> Στην **πρώτη εκκίνηση** το πρόγραμμα ανοίγει αυτόματα στις Ρυθμίσεις, ώστε να καταχωρίσεις στοιχεία & σχολεία.

### Αποτύπωση
Μηνιαία στατιστικά στοιχεία (επιλέγεις **μήνα** και **έτος** στο πάνω μέρος):
- **Μαθητές ανά βαθμίδα**: Πρωτοβάθμια (Νηπιαγωγείο + Δημοτικό) και Δευτεροβάθμια (Γυμνάσιο + Λύκειο + ΕΠΑΛ),
  με ανάλυση ανά κατηγορία και φύλο.
- **Μαθητές ανά σχολείο & φύλο**: π.χ. *2ο Δημοτικό — Άρρενες 2, Θήλεις 3, Σύνολο 5*.
- **Εξαγωγή σε doc** (κουμπί πάνω δεξιά): αποθηκεύει όλη την αποτύπωση σε αρχείο **Word (.docx)** με
  τακτοποιημένους πίνακες (σύνολα, ανά βαθμίδα με υποσύνολα, ανά σχολείο & φύλο), έτοιμο για εκτύπωση.

Η αποτύπωση είναι **στιγμιότυπο τέλους μήνα**: μετρά όσους ήταν εγγεγραμμένοι έως το τέλος του επιλεγμένου
μήνα (μαθητής που διαγράφηκε αργότερα εξακολουθεί να μετρά για τους προηγούμενους μήνες).

### Παρατηρητήριο
Έτοιμα κείμενα για τη φόρμα του Παρατηρητηρίου, ανά **15νθήμερο** (επιλέγεις μήνα, έτος και 1ο/2ο μισό).
Κάθε πεδίο είναι **επεξεργάσιμο** και έχει κουμπί **αντιγραφής** για επικόλληση.
- **Α1 — Εγγραφές & Διαγραφές** (ένα ενιαίο, αντιγράψιμο μπλοκ): πρώτα οι **εγγραφές** της περιόδου ανά
  βαθμίδα & σχολείο με σύνολο εγγραφών (μετρά με βάση την **ημερομηνία εγγραφής**, ώστε μαθητής που
  εγγράφηκε στην περίοδο να μετρά **ακόμη κι αν διαγράφηκε αργότερα**), στη συνέχεια οι **διαγραφές** της
  περιόδου **ανά σχολείο** με σύνολο (χωρίς ονόματα/ΔΙΚΑ) και στο τέλος το **τελικό σύνολο ενεργών**
  (εγγραφές μείον διαγραφές).
- **Α1.2–1.4** (ΔΥΕΠ / με & χωρίς Τμήμα Υποδοχής) και **Α1.5 / Α3.1** (ειδική αγωγή, ασυνόδευτοι):
  αποτυπώνουν την **τρέχουσα εικόνα** — υπολογίζονται από τους **ενεργούς (εγγεγραμμένους)** μαθητές,
  ανεξάρτητα από την επιλεγμένη περίοδο.
- **Γ — Ζητήματα σχολικής διαρροής**: **Γ1** = αριθμός μαθητών που **διέκοψαν τη φοίτηση** μέσα στην
  περίοδο (διαγράφηκαν ενώ ήταν εγγεγραμμένοι· **εξαιρούνται οι απόφοιτοι**). **Γ3** = οι **λόγοι διακοπής**
  ομαδοποιημένοι με πλήθος, χωρίς προσωπικά στοιχεία (π.χ. *«Αποχώρηση από την δομή (3 μαθητές) - Άτυπη
  φυγή (1 μαθητής)»*). Ο λόγος είναι αυτός που συμπληρώνεις **κατά τη διαγραφή** του μαθητή.

### Ημερολόγιο
Ημερολόγιο με προβολές **Μήνας / Εβδομάδα / Ημέρα**. Οι ημέρες με γεγονότα έχουν **κόκκινη βούλα**.
- **Αυτόματα γεγονότα μαθητών**: **Άφιξη** (μπλε), **Εγγραφή** (πράσινο), **Διαγραφή** (κόκκινο) παράγονται
  αυτόματα από τα δεδομένα. Όταν πολλοί μαθητές έχουν το ίδιο γεγονός την ίδια ημέρα, εμφανίζονται
  **ομαδοποιημένα** (π.χ. *«Άφιξη 30»*). Ανοίγοντας την ημέρα και **πατώντας στην ομάδα**, αναπτύσσεται η
  λίστα με τα **πλήρη ονόματα & ΔΙΚΑ** κάθε μαθητή· από εκεί μπορείς να **αλλάξεις την ημερομηνία** του
  γεγονότος για κάθε μαθητή (✏️).
- **Χειροκίνητες σημειώσεις**: με **«Νέα σημείωση»** προσθέτεις σημείωση (ημερομηνία, τίτλος, κείμενο).
  Πατώντας την ημέρα και μετά ✏️ σε μια σημείωση μπορείς να την **επεξεργαστείς**, να τη **μετακινήσεις**
  (αλλάζοντας την ημερομηνία) ή να τη **διαγράψεις**.

## Μαζικές ενέργειες

Σε κάθε λίστα μπορείς να επιλέξεις μαθητές με τα **πλαίσια επιλογής** (☑) — το πάνω πλαίσιο επιλέγει
όλους. Εμφανίζεται μπλε μπάρα με τις διαθέσιμες μαζικές ενέργειες:
- **Αφίξεις**: Μαζική εγγραφή (αυτόματη ή σε συγκεκριμένο σχολείο) · Μαζική διαγραφή.
- **Μαθητές**: Μαζική έκδοση εγγράφων (όλα τα templates, ένα PDF ανά μαθητή σε φάκελο) · Μαζική διαγραφή.
- **Διαγραφές**: Μαζική επαναφορά · Οριστική διαγραφή.

Επιπλέον, σε **Αφίξεις** και **Μαθητές** υπάρχει ξεχωριστό κουμπί **«Μαζική διαγραφή με ΔΙΚΑ»**
(δεν απαιτεί πλαίσια επιλογής — δίνεις λίστα αριθμών ΔΙΚΑ).

## Εισαγωγή από XLSX

Αναγνωρίζονται αυτόματα οι στήλες (ανεξαρτήτως τόνων/πεζών-κεφαλαίων): **Μονάδα, ΔΙΚΑ, Όνομα, Επώνυμο,
Πατρώνυμο, Μητρώνυμο, Φύλο, Γλώσσα, Ιθαγένεια, Ημερομηνία γέννησης**. Τυχόν επιπλέον στήλες αγνοούνται.
Η **Ημ. άφιξης** συμπληρώνεται αυτόματα κατά την εισαγωγή. Κρατούνται μόνο οι μαθητικής ηλικίας· οι
υπόλοιποι (ενήλικες) εξαιρούνται με σχετική σύνοψη.

Κάθε εισαγωγή («batch») εμφανίζεται με **διαφορετική απόχρωση** και η νεότερη μπαίνει στην κορυφή. Το όνομα
της τελευταίας λίστας φαίνεται πάντα στις καρτέλες **Αφίξεις** και **Μαθητές** («Τελευταία λίστα: …»).

Κατά την εισαγωγή γίνεται **αντιπαραβολή** με τους ήδη καταχωρημένους: αν κάποιοι μαθητές υπάρχουν στο
Μαθητολόγιο αλλά **λείπουν από τη νέα λίστα** (πιθανή αποχώρηση), ανοίγει παράθυρο που σου επιτρέπει να τους
διαγράψεις μαζικά ή μεμονωμένα (οι αφίξεις οριστικά, οι εγγεγραμμένοι στις «Διαγραφές»).

## Έκδοση εγγράφων

Τα πρότυπα (`.docx` / `.pptx`) περιέχουν tokens που συμπληρώνονται αυτόματα:

| Token | Περιεχόμενο |
|---|---|
| `{{Όνομα}}` `{{Επώνυμο}}` `{{Πατρώνυμο}}` `{{Μητρώνυμο}}` | στοιχεία μαθητή |
| `{{ΔΙΚΑ}}` `{{Φύλο}}` `{{Γλώσσα}}` `{{Ιθαγένεια}}` | στοιχεία μαθητή |
| `{{ΗμΓεν}}` `{{Μονάδα}}` | ημ. γέννησης / μονάδα |
| `{{Σχολείο}}` `{{Τάξη}}` / `{{TAXI}}` | σχολείο & τάξη εγγραφής |
| `{{ΣΕΠ}}` `{{Νομός}}` `{{Δομή}}` `{{PERIF}}` | από τις Ρυθμίσεις (ΣΕΠ, Νομός, Δομή, Περιφερειακή Δ/νση) |
| `{{signee}}` `{{signee.prop}}` | υπογράφων & ιδιότητά του (βλ. παρακάτω) |
| `{{signee.note}}` | παρένθεση κάτω από την υπογραφή (π.χ. αναμονή επιτρόπου· βλ. «Πακέτο εγγραφής») |
| `{{DATE}}` | σημερινή ημερομηνία |
| `{{?Οτιδήποτε}}` | ζητιέται κατά την έκδοση & απομνημονεύεται (βλ. παρακάτω) |

**Υπογράφων:** όταν ένα έγγραφο περιέχει `{{signee}}`, κατά την έκδοση ερωτάσαι ποιος υπογράφει:
**Πατέρας** / **Μητέρα** (ονοματεπώνυμο = Πατρώνυμο/Μητρώνυμο + Επώνυμο μαθητή) / **ΣΕΠ** / **Άλλο**
(δικό σου όνομα + ιδιότητα, π.χ. αδερφός/επίτροπος). Στη μαζική έκδοση η επιλογή εφαρμόζεται ανά μαθητή
(χωρίς «Άλλο»). Η ιδιότητα γράφεται στο `{{signee.prop}}`.

**Πεδία που ζητιούνται κατά την έκδοση:**

- **Token με `?` μπροστά** (π.χ. `{{?Διεύθυνση}}`, `{{?Κινητό}}`, `{{?ΤΚ}}`): κατά την έκδοση ζητιέται να
  συμπληρώσεις την τιμή, με **ετικέτα το κείμενο μετά το `?`**. Χρήσιμο για **σταθερά προσωπικά στοιχεία** που
  δεν μπαίνουν στις Ρυθμίσεις. Η τιμή **απομνημονεύεται** και προ-συμπληρώνεται στις επόμενες εκδόσεις (και
  γεμίζει αυτόματα στη μαζική έκδοση). Τη βλέπεις/καθαρίζεις από **Ρυθμίσεις → Πρότυπα εγγράφων → Αποθηκευμένα
  στοιχεία**.
- **Άλλο άγνωστο token χωρίς `?`** (π.χ. `{{Σχολείο προορισμού}}`): ζητιέται **κάθε φορά** με το όνομά του ως
  ετικέτα και **δεν** απομνημονεύεται (στη μαζική έκδοση μένει κενό).

Η μετατροπή σε PDF γίνεται αυτόματα (μέσω LibreOffice) — δεν χρειάζεται χειροκίνητη εξαγωγή.

**Δικά σου πρότυπα:** από **Ρυθμίσεις → Πρότυπα εγγράφων** μπορείς να προσθέσεις δικά σου αρχεία
`.docx`/`.pptx` (και να διαγράψεις όσα πρόσθεσες). Αποθηκεύονται τοπικά στον φάκελο δεδομένων του χρήστη,
οπότε **διατηρούνται στις ενημερώσεις**. Η λίστα δείχνει τα tokens που εντοπίστηκαν σε κάθε πρότυπο
(πράσινα τα `?`-πεδία, πορτοκαλί τα άγνωστα που ζητιούνται ανά έγγραφο). Τα ενσωματωμένα πρότυπα δεν διαγράφονται.

## Πακέτο εγγραφής (ανά κατηγορία μαθητή)

Από την καρτέλα **Μαθητές**, το εικονίδιο **φάκελος** ανά μαθητή ανοίγει τη ροή «Πακέτο εγγραφής»: εκδίδει
**μαζί όλα τα έγγραφα εγγραφής** του μαθητή, ανάλογα με την **κατηγορία**, και τα αποθηκεύει σε φάκελο
`<Όνομα>_<Επώνυμο>_<ΔΙΚΑ>`.

**Κατηγορίες & έγγραφα:**

| Κατηγορία | Υπογράφει | Ιδιαιτερότητα |
|---|---|---|
| Ανήλικος με οικογένεια | γονέας/συγγενής | — |
| Ασυνόδευτος με επίτροπο | ο επίτροπος | — |
| Ασυνόδευτος χωρίς επίτροπο | ο **ΣΕΠ** | προστίθεται στο `{{signee.note}}`: «Σε αναμονή ορισμού επιτρόπου από την Εισαγγελία νομού …» |
| Ενήλικας | ο ίδιος | χρησιμοποιείται η **ΥΔ-ΖΕΠ ενηλίκων** |

Όλες οι κατηγορίες περιλαμβάνουν **Αίτηση εγγραφής**, **ΥΔ-ΖΕΠ**, **ΑΔΥΜ** και **Ταυτοποιητικό**.

- **Ενήλικες:** σημειώστε τη στήλη **«Ενήλικας»** στην καρτέλα Μαθητές (οι ενήλικες κατατάσσονται σε κανονική
  βαθμίδα, οπότε δεν αναγνωρίζονται από την ηλικία). Η κατηγορία προτείνεται αυτόματα αλλά αλλάζει χειροκίνητα.
- **Χειρόγραφη υπογραφή:** σε κάθε έγγραφο με `{{signee}}` ο υπογράφων μπορεί να **σχεδιάσει την υπογραφή** με
  το ποντίκι· τοποθετείται πάνω στο `{{signee}}` (καλύπτει το όνομα, με διαφανές φόντο). Αν μείνει κενή,
  τυπώνεται το όνομα.
- **Ταυτοποιητικό:** λήψη με **κάμερα** ή **επιλογή αρχείου** εικόνας.
- **Νομός σε γενική:** για την παρένθεση του ΣΕΠ, ορίστε **Ρυθμίσεις → «Νομός (γενική)»** (π.χ. *Δράμας*).
- **Φάκελος αποθήκευσης:** επιλέγεται/θυμάται μέσα από τη ροή (προεπιλογή: *Έγγραφα ▸ Πακέτα εγγραφής*).

## Αντίγραφα ασφαλείας

- **Backup** → εξαγωγή ολόκληρης της βάσης σε αρχείο `.sqlite`.
- **Επαναφορά** → φόρτωση από αρχείο backup (αντικαθιστά τα τρέχοντα δεδομένα).
- **Αυτόματα αντίγραφα** → από **Ρυθμίσεις → Αυτόματα αντίγραφα ασφαλείας** ορίζεις φάκελο και συχνότητα
  (Καθημερινά / Εβδομαδιαία / Μηνιαία). Ο έλεγχος γίνεται κάθε φορά που ανοίγει η εφαρμογή και κρατούνται
  τα τελευταία Ν αντίγραφα. Υπάρχει και κουμπί «Backup τώρα».

## Κλίμακα τάξεων (προεπιλογή, σχ. έτος 2025-2026)

Σχολική ηλικία = γεννηθέντες **2008–2021**:

## Τεχνικές πληροφορίες (για προγραμματιστές)

**Stack:** Electron · React + Vite + Tailwind · SQLite (`sql.js`, WASM) · SheetJS (`xlsx`) · `pizzip` ·
`docx` (εξαγωγή αποτύπωσης σε Word) · LibreOffice (headless) για docx/pptx → PDF.

```bash
npm install
npm run dev      # Vite + Electron (ανάπτυξη)
npm run dist     # δημιουργία installer .exe (Windows) στο release/
```

- Τα πρότυπα εγγράφων: `resources/templates/` (`.docx`/`.pptx`).
- Για PC χωρίς Office, τοποθέτησε portable LibreOffice στο `resources/libreoffice/` (το `soffice(.exe)`
  ή τον φάκελο `program/`).
- Το τελικό `.exe` χτίζεται καλύτερα σε Windows ή GitHub Actions (windows runner).
