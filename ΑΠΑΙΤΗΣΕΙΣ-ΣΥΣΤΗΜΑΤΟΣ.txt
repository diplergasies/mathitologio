  Έκδοση εφαρμογής: 1.4.3
========================================================

ΛΕΙΤΟΥΡΓΙΚΟ ΣΥΣΤΗΜΑ
-------------------
- Windows 10 ή Windows 11
- ΑΡΧΙΤΕΚΤΟΝΙΚΗ: 64-bit (x64) ΑΠΟΚΛΕΙΣΤΙΚΑ

  !!! ΠΡΟΣΟΧΗ !!!
  Η εφαρμογή ΔΕΝ τρέχει σε 32-bit Windows.
  Σε υπολογιστή με 32-bit Windows εμφανίζεται το μήνυμα:
  «Δεν είναι έγκυρη εφαρμογή Win32».
  Αυτό ΔΕΝ σημαίνει ότι το αρχείο είναι χαλασμένο — απλώς
  ο υπολογιστής είναι 32-bit και δεν μπορεί να τρέξει
  64-bit προγράμματα.

ΔΕΝ ΥΠΟΣΤΗΡΙΖΟΝΤΑΙ (η εφαρμογή δεν θα ανοίξει)
---------------------------------------------
- Windows 7, Windows 8, Windows 8.1
- Windows Vista, Windows XP
- Οποιαδήποτε έκδοση 32-bit των Windows
  (ο σύγχρονος πυρήνας Electron 33 απαιτεί Windows 10 64-bit)

ΥΛΙΚΟ (HARDWARE)
----------------
- Μνήμη RAM: 4 GB ελάχιστο  (8 GB συνιστώμενο)
- Ελεύθερος χώρος δίσκου: ~1.5 GB
    • ~1 GB για την εγκατεστημένη εφαρμογή
    • ~300 MB για το αρχείο εγκατάστασης κατά τη λήψη
- Επεξεργαστής: οποιοσδήποτε σύγχρονος 64-bit (x64)
- Οθόνη: ανάλυση 1366×768 ή μεγαλύτερη

ΠΕΡΙΛΑΜΒΑΝΟΝΤΑΙ — ΔΕΝ ΧΡΕΙΑΖΟΝΤΑΙ ΞΕΧΩΡΙΣΤΕΣ ΕΓΚΑΤΑΣΤΑΣΕΙΣ
-----------------------------------------------------------
- LibreOffice (για τη δημιουργία εγγράφων/PDF) είναι ΕΝΣΩΜΑΤΩΜΕΝΟ.
  Δεν χρειάζεται να εγκαταστήσετε Microsoft Office ή LibreOffice.
- Δεν απαιτείται σύνδεση στο Internet για τη λειτουργία
  (η εφαρμογή δουλεύει εκτός σύνδεσης / offline).

ΠΩΣ ΝΑ ΕΛΕΓΞΕΤΕ ΑΝ Ο ΥΠΟΛΟΓΙΣΤΗΣ ΕΙΝΑΙ 64-bit
----------------------------------------------
1. Δεξί κλικ στο «Αυτός ο υπολογιστής» (ή «Ο υπολογιστής μου»)
2. Επιλέξτε «Ιδιότητες»
3. Δείτε τη γραμμή «Τύπος συστήματος» (System type):
     • «Λειτουργικό σύστημα 64 bit»  →  ΟΚ, η εφαρμογή τρέχει
     • «Λειτουργικό σύστημα 32 bit»  →  ΔΕΝ τρέχει
