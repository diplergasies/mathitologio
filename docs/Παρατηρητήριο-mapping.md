# Παρατηρητήριο Εκπαίδευσης Προσφύγων — αντιστοίχιση πεδίων φόρμας ↔ δεδομένα εφαρμογής

> Σημείωση συνέχισης εργασίας (μεταξύ Chromebook ↔ Windows). Τελευταία ενημέρωση: 2026-06-24.

## Τι είναι
Κάθε ΣΕΠ συμπληρώνει το **Παρατηρητήριο Εκπαίδευσης Προσφύγων** (ΥΠΑΙΘ/ΙΕΠ), ηλεκτρονική φόρμα **κάθε 15 ημέρες**
(ν.4547/2018 αρ.77, ΚΥΑ ΦΕΚ 2985/Β/2017). **Δεν έχει API** → χειροκίνητη μεταφορά τιμών.
Στόχος feature: προβολή «Παρατηρητήριο» που υπολογίζει τα αριθμητικά πεδία με κουμπί **📋 Αντιγραφή** ανά πεδίο.

Πηγαία έγγραφα (εκτός repo, `/home/katsanx/platform-docs/`): `platform fields.txt` (ζωντανή λίστα πεδίων Α–Θ),
`platform_instructions.docx.md` (παλαιότερη δομή, κεφάλαια Α–Η).

## Συμπέρασμα
~80% της φόρμας είναι **ελεύθερο κείμενο** (συνεργασίες, καλές πρακτικές, υλικό, σχόλια) → δεν αυτοματοποιείται.
Μόνο τα **αριθμητικά πεδία** τροφοδοτούνται από την εφαρμογή.

## Αντιστοίχιση πεδίων
Υπόμνημα: ✅ τώρα · 🟡 φθηνό (νέο flag) · 🔴 χρειάζεται υποσύστημα παρουσιών · ⬜ χειροκίνητο

| Πεδίο | Κατάσταση | Τι χρειάζεται |
|---|---|---|
| **Α1** Σύνολο εγγραφών (μηνιαία), ανά Πρωτοβάθμια/Δευτεροβάθμια + αγόρια/κορίτσια | ✅ τώρα | Η καρτέλα Αποτύπωση ήδη υπολογίζει· ίσως ως λόγος `εγγραφές/φιλοξενούμενοι` = εγγεγραμμένοι ÷ (εγγεγραμμένοι + σχολικής ηλικίας στις Αφίξεις) |
| **Α1.2** ΔΥΕΠ / **Α1.3** με Τ.Υ / **Α1.4** χωρίς Τ.Υ | 🟡 | Νέο πεδίο **τύπου προγράμματος** στα σχολεία (ΔΥΕΠ/Τ.Υ/γενική χωρίς Τ.Υ/ειδική) |
| **Α1.5** ειδική αγωγή / αναπηρία | 🟡 | Νέο flag **ΕΙΔ. ΑΓΩΓΗΣ/αναπηρίας** ανά μαθητή |
| **Α2, Α2.1–2.3** ενεργοί / τακτική / ελλιπής (<3×/εβδ) / μηδενική φοίτηση | 🔴 | **Υποσύστημα παρουσιών** |
| **Α3.1** εγγραφές ασυνόδευτων | 🟡 | Νέο boolean **«Ασυνόδευτος»** ανά μαθητή |
| **Α3.2–3.4** ενεργοί/τακτική/ελλιπής ασυνόδευτοι | 🔴 | Flag ασυνόδευτου + παρουσίες |
| **Β2** προήχθησαν/απολύθηκαν (τέλος έτους) | 🟡 | Εμφάνιση από το υπάρχον feature **Προβιβασμού** |
| **Β1** συμμετοχή εξετάσεων / **Β3** πανελλήνιες | ⬜ | Χειροκίνητο |
| **Γ1/Γ2** διακοπή φοίτησης + αιτία | 🟡 | **Κατηγορίες λόγου διαγραφής** (αντιστοίχιση στις επιλογές Γ2) στο soft-delete |
| **Δ, Ε, ΣΤ, Ζ, Θ** (συνεργασίες, υλικό, δράσεις, σχόλια) | ⬜ | Αφήγηση — χειροκίνητο |

## Σημεία-κλειδιά
1. **Σήμερα χωρίς αλλαγές μοντέλου:** ήδη τροφοδοτούνται **Α1** + **Β2**.
2. **Τρία φθηνά flags** ξεκλειδώνουν τα περισσότερα αριθμητικά: **Ασυνόδευτος** (boolean), **τύπος προγράμματος σχολείου**, **λόγος διαγραφής**.
3. **Το μόνο ακριβό κενό = παρουσίες** (Α2.x/Α3.2–3.4) — ίδιο υποσύστημα με το βασικό pain «ποιος φοιτά πραγματικά», άρα αξίζει διπλά.

## Ανοιχτά ερωτήματα (προς χρήστη)
- **Σημασιολογία περιόδου:** Α1/Α2 = *τρέχον σύνολο* εγγεγραμμένων ή *νέες εγγραφές του 15νθημέρου*;
- **Μορφή Α1:** λόγος `εγγραφές/φιλοξενούμενοι` (π.χ. 4/5) ή σκέτος αριθμός εγγεγραμμένων;

## Συμφωνημένη σειρά υλοποίησης
1. **Αυτόματα αντίγραφα ασφαλείας + επαναφορά** (δεν υπάρχει σήμερα· διανεμημένες εγκαταστάσεις → κίνδυνος ολικής απώλειας)
2. Πίνακας/worklist εγγραφών (dashboard)
3. Βελτιώσεις εγγράφων (templates από χρήστη, κατάσταση εγγράφων, μνήμη υπογράφοντα)
4. Αυτή η προβολή «Παρατηρητήριο»
5. (μεγάλο) Υποσύστημα παρουσιών — ξεκλειδώνει Α2/Α3
